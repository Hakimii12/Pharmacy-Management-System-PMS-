# Pharmacy Frontend

TypeScript rebuild of the Hamza Masjid Pharmacy UI. React + Vite, Redux Toolkit / RTK Query, Tailwind, Dexie offline store, and a Workbox service worker.

## Scripts

```bash
npm install
npm run dev        # http://localhost:5173 (proxies /api → VITE_API_URL)
npm run build      # typecheck + production bundle + service worker
npm run preview    # serve dist/
npm run typecheck
```

## Environment

Copy or edit `.env`:

```
VITE_API_URL=http://localhost:3000
VITE_CURRENCY=ETB
```

In development the Vite proxy forwards `/api` to `VITE_API_URL` so the JWT cookie stays same-origin.

## Offline / PWA

- Reference data (products, catalog, notifications) is mirrored into IndexedDB via Dexie whenever a fetch succeeds.
- Offline writes (cash/credit sales, confirm/abort, credit payments) go into a Dexie sync queue and replay sequentially on reconnect (Background Sync when available, `online` event otherwise).
- The sync tray in the top bar shows queued / failed mutations.
- Install and update banners live in the app shell; icons and `manifest.webmanifest` are generated by `vite-plugin-pwa`.

Regenerate PWA icons:

```bash
node scripts/gen-icons.mjs
```
